# 金蝶云星空连接器使用流程

## 第一步：配置连接信息

访问应用后，首先需要填写金蝶云星空的连接配置：

### 必填项
- **ServerUrl 星空域名**: 金蝶云星空服务器地址（默认：http://3xcrm.imwork.net:8751）
- **AcctID 账套 ID**: 账套标识（默认：6627fe99cbe8ec）
- **AppID 应用 ID**: 应用标识（默认：339518_1+aqQaDLTpqYT4WsS01A0ZXJ2qx/WqpG）
- **AppSec 应用密钥**: 应用密钥（默认：e82884a385b74fc58062fd825c3956f7）

### 非必填项
- **OrgNum 组织编码**: 组织编码（可选）
- **LCID 语言编码**: 语言编码，默认 2052（简体中文）
- **UserName 登录账号**: 登录用户名（可选）

### 登录测试
点击"登录测试"按钮可以验证配置是否正确：
1. 系统会自动生成签名（使用 SHA256 加密算法）
2. 调用金蝶登录接口验证配置
3. 登录成功后，"下一步"按钮才会变为可点击状态

## 第二步：选择单据类型

登录成功后，进入单据选择页面：

### 功能说明
1. **单据列表**: 显示所有可用的单据类型（从 `/forms.json` 加载）
2. **搜索过滤**: 可以通过表单 ID 或单据名称进行搜索过滤
3. **选择单据**: 点击"选择"按钮选择需要查询的单据类型

### 可用单据示例
- BD_MATERIAL - 物料
- SAL_ORDER - 销售订单
- PUR_ORDER - 采购订单
- BOM_BILL - BOM 单
- PROD_ORDER - 生产订单
- INV_BAL - 库存余额
- CST_CUSTOMER - 客户
- SUPPLIER - 供应商

### 查询字段
选择单据后，点击"查询字段"按钮：
1. 调用金蝶元数据查询接口
2. 获取该单据类型的所有可用字段
3. 展示字段列表供用户查看

### 字段信息
每个字段包含：
- **字段标识 (Key)**: 字段的唯一标识符
- **字段名称 (Caption)**: 字段的显示名称
- **数据类型**: 文本、数字、日期、布尔等

## 技术实现

### 签名算法
按照金蝶官方 C# demo 实现：
```javascript
1. 将账套 ID、用户名、应用 ID、应用秘钥、时间戳放入数组
2. 对数组进行排序（StringComparer.Ordinal）
3. 拼接成字符串
4. 使用 SHA256 加密生成签名
5. 时间戳使用秒级（Math.floor(Date.now() / 1000)）
```

### 接口调用
1. **登录接口**: `/K3Cloud/Kingdee.BOS.WebApi.ServicesStub.AuthService.LoginBySign.common.kdsvc`
2. **元数据查询接口**: `/K3Cloud/Kingdee.BOS.WebApi.ServicesStub.DynamicFormService.QueryBusinessInfo.common.kdsvc`

### 配置文件
- **forms.json**: 单据类型配置文件，位于 `public/forms.json`
- 可以根据实际需求修改和扩展单据列表

## 注意事项

1. 确保网络连接正常，能够访问金蝶服务器
2. 配置信息必须准确无误
3. 登录测试通过后才能进行下一步操作
4. 不同版本的金蝶云星空可能返回的元数据结构略有不同
